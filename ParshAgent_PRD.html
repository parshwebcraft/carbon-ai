Executive Summary
ParshAgent is an enterprise-grade Omnichannel AI Sales Engine combining Voice-First Outreach (Vapi/Omnidim) with real-time Meta WhatsApp Cloud API conversational qualification, automated appointment booking (Google Calendar/Meet), Razorpay digital payment link closures, and an AiSensy-grade Bulk Marketing & Interactive Flow builder — completely eliminating 3rd-party recurring SaaS fees.

1. Architectural Overview & Product Vision

Traditional sales workflows suffer severe lead leakage between customer calls and subsequent text follow-ups. ParshAgent closes this gap with a closed-loop automated architecture:

Phase Action & AI Trigger Outcome & Telemetry
1. Inbound/Outbound Call AI Voice Agent conducts 60-90s initial discovery. Real-time transcript extracted via Webhook. Lead qualified; CRM status set to Call Completed. Intent summary generated.
2. Instant WhatsApp Handoff Within 5 seconds of call disconnect, Meta Cloud API sends personalized portfolio brochure & summary. Double Blue Tick verified. Conversation window opened (24-hour service window).
3. Conversational AI Bot Multi-turn LLM dialog identifies requirements, answers questions, handles pricing objections. Lead attributes (budget, service_type, timeline) updated in PostgreSQL.
4. Meeting Scheduling Google Calendar free/busy slots inspected; 2 optimal slots offered. Google Meet link issued. Calendar invite sent to client; Instant WhatsApp Alert sent to Gauransh's phone.
5. Payment Closure Razorpay API generates customized token advance payment link with one-click UPI checkout. Razorpay webhook moves CRM card to Closed / Won; automated tax invoice sent.

8. Infrastructure & Security Specifications

  • Host Environment: Ubuntu 24.04 LTS (103.190.54.151), Nginx SSL Reverse Proxy, Python 3.12, FastAPI, Gunicorn Uvicorn workers.
  • Database Layer: PostgreSQL 16 (parshagent_db) with optimized indexes on phone, wa_message_id, and lead_id.
  • Meta API Security: Permanent non-expiring System User Token (expires_at: 0) stored in root-protected .env.
  • Reliability: Systemd managed service (Restart=always), non-blocking FastAPI BackgroundTasks ensuring Meta webhook responses in <50ms.
